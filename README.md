## Getting Started

### Prerequisites
- Node.js 18+ or pnpm 12+

### Installation

```bash
# Clone the repository
git clone https://github.com/Fadydesoky/my-fadydesokysaeedabdelaziz-portfolio.git
cd my-fadydesokysaeedabdelaziz-portfolio

# Install dependencies (using pnpm)
pnpm install

# Or using npm
npm install

# Or using yarn
yarn install
```

### Development

Run the development server:

```bash
pnpm dev
# or
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

The app auto-updates as you edit files in the `app` directory.

### Build for Production

```bash
pnpm build
pnpm start
```
